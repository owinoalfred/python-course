# Instructor notes — 4.2 Parameters and Arguments

**Module 4: Functions and Modules**

## Teaching objectives

- Teach core concept of Parameters and Arguments.
- Guide students through edge cases.

## Likely misconceptions

| Misconception | Correction to drive home |
| --- | --- |
| Thinking Parameters and Arguments is static | Clarify dynamic runtime execution in CPython |

## Difficult concepts

- Understanding edge-case handling in Parameters and Arguments.

## Demonstration suggestions

- Live demo of Parameters and Arguments in python REPL.

## Discussion questions

- Why is Parameters and Arguments preferred in this context?

## Common student errors

| Error | Why it happens | Intervention |
| --- | --- | --- |
| IndexError / KeyError in Parameters and Arguments | Accessing elements without bounds check | Add length check or try-except |
