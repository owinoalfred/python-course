# 4.3 — Return Values, Scope, and Closures

**Module 4: Functions and Modules**

LEGB rule, global and nonlocal keywords, closures, and returning values.

## Why this topic matters

Understanding variable scope and closures prevents state leak bugs.

## Learning objectives

1. Understand LEGB scope resolution.
2. Use nonlocal in nested functions.
3. Construct closures to encapsulate state.

## Prerequisites

- Topic 4.2 Parameters
