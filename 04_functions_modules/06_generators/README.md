# 4.6 — Generators

**Module 4: Functions and Modules**

yield statement, generator functions, generator expressions, and memory optimization.

## Why this topic matters

Generators stream data lazily with O(1) memory footprint.

## Learning objectives

1. Write generator functions using yield.
2. Understand lazy evaluation semantics.
3. Use itertools for streaming algorithms.

## Prerequisites

- Topic 4.5 Functional Tools
