# 4.7 — Decorators

**Module 4: Functions and Modules**

Function decorators, functools.wraps, parameterized decorators, and class decorators.

## Why this topic matters

Decorators inject cross-cutting concerns like logging, timing, and security checks cleanly.

## Learning objectives

1. Write function decorators.
2. Preserve metadata with @functools.wraps.
3. Pass parameters to decorators.

## Prerequisites

- Topic 4.6 Generators
