# 4.4 — Advanced Function Concepts

**Module 4: Functions and Modules**

Higher-order functions, first-class functions, and recursion.

## Why this topic matters

Functions are first-class objects in Python and can be passed as arguments.

## Learning objectives

1. Pass functions as first-class objects.
2. Implement higher-order functions.
3. Write recursive algorithms with base cases.

## Prerequisites

- Topic 4.3 Scope and Closures
