# 4.1 — Defining and Calling Functions

**Module 4: Functions and Modules**

Function definitions, invocation, parameter passing, and docstrings.

## Why this topic matters

Functions encapsulate reusable blocks of logic.

## Learning objectives

1. Define functions with def.
2. Invoke functions and pass arguments.
3. Write docstrings.

## Prerequisites

- Module 3 Core Data Structures
