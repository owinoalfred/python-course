# 4.8 — Modules and Packages

**Module 4: Functions and Modules**

import statements, __init__.py, relative imports, and module search path.

## Why this topic matters

Modules organize code into reusable maintainable namespaces.

## Learning objectives

1. Import standard and custom modules.
2. Structure Python packages with __init__.py.
3. Understand sys.path resolution.
