# 4.9 — Virtual Environments and Package Management

**Module 4: Functions and Modules**

venv, pip, requirements.txt, and pyproject.toml.

## Why this topic matters

Isolated virtual environments prevent dependency version conflicts.

## Learning objectives

1. Create virtual environments with venv.
2. Manage dependencies with pip and requirements.txt.
3. Configure pyproject.toml.
