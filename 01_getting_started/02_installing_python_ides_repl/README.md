# 1.2 — Installing Python, IDEs, and the REPL

**Module 1: Getting Started with Python**

Setting up Python 3.14, VS Code, Jupyter, and mastering interactive development with the REPL.

## Why this topic matters

A reliable development environment is essential for professional software engineering.

## Learning objectives

1. Install and verify Python 3.14.
2. Configure VS Code and Jupyter notebooks.
3. Use the Python REPL effectively.

## Prerequisites

- Topic 1.1 Introduction to Python

3. Attempt `exercises.ipynb` — all eleven tasks.

6. Build the mini-project and write its tests.
