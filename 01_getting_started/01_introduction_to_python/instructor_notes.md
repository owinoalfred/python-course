# Instructor notes — 1.1 Introduction to Python

**Module 1: Getting Started with Python**

## Teaching objectives

- Teach core concept of Introduction to Python.
- Guide students through edge cases.

## Likely misconceptions

| Misconception | Correction to drive home |
| --- | --- |
| Thinking Introduction to Python is static | Clarify dynamic runtime execution in CPython |

## Difficult concepts

- Understanding edge-case handling in Introduction to Python.

## Demonstration suggestions

- Live demo of Introduction to Python in python REPL.

## Discussion questions

- Why is Introduction to Python preferred in this context?

## Common student errors

| Error | Why it happens | Intervention |
| --- | --- | --- |
| IndexError / KeyError in Introduction to Python | Accessing elements without bounds check | Add length check or try-except |

## Recommended pacing

2 hours lecture + 3 hours lab exercises.

## Extension activities

- Advanced optimization profiling.

## Assessment advice

Evaluate against rubric.md.

## Differentiation

**If students are struggling:** Provide starter template.

**If students finish early:** Have student write custom benchmark script.
