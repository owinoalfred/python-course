# 1.4 — Variables, Naming Conventions, and Dynamic Typing

**Module 1: Getting Started with Python**

Name-binding model, snake_case conventions, dynamic typing, and garbage collection basics.

## Why this topic matters

Variables in Python are reference labels bound to objects, not memory containers.

## Learning objectives

1. Explain the name-binding model.
2. Apply snake_case and PEP 8 naming conventions.
3. Understand dynamic typing.

- Topic 1.3 Python Syntax
