# Module 7 — File Handling and Working with Data

**Directory:** `07_files_data/` &nbsp;|&nbsp; **ROBO-X milestone:** M7 &nbsp;|&nbsp; **Topics:** 6

Read and write real data. You will use pathlib and context managers, parse and emit JSON and CSV, and apply regular expressions, then join it all into a small data pipeline for flight-test and telemetry records.

## What you will be able to do

- Read and write files safely with context managers and the right encodings.
- Manipulate filesystem paths portably with ``pathlib``.
- Parse and serialise JSON and CSV, including error handling.
- Apply regular expressions to extract structured fields from logs.
- Assemble a small end-to-end data pipeline.
