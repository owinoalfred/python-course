# 7.3 — JSON and CSV

**Module 7: File Handling and Working with Data**

json module (dumps, loads, dump, load) and csv module (reader, writer, DictReader, DictWriter).

## Why this topic matters

JSON and CSV are universal formats for configuration, serialization, and telemetry datasets.

## Learning objectives

1. Serialize and deserialize JSON.
2. Read and write CSV files with csv.reader and csv.DictReader.
3. Handle parsing errors.
