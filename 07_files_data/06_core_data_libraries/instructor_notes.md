# Instructor notes — 7.6 Core Data Libraries

**Module 7: File Handling and Working with Data**

## Teaching objectives

- Teach core concept of Core Data Libraries.
- Guide students through edge cases.

## Likely misconceptions

| Misconception | Correction to drive home |
| --- | --- |
| Thinking Core Data Libraries is static | Clarify dynamic runtime execution in CPython |

## Difficult concepts

- Understanding edge-case handling in Core Data Libraries.

## Demonstration suggestions

- Live demo of Core Data Libraries in python REPL.

## Discussion questions

- Why is Core Data Libraries preferred in this context?

## Common student errors

| Error | Why it happens | Intervention |
| --- | --- | --- |
| IndexError / KeyError in Core Data Libraries | Accessing elements without bounds check | Add length check or try-except |

## Recommended pacing

2 hours lecture + 3 hours lab exercises.

## Extension activities

- Advanced optimization profiling.

## Assessment advice

Evaluate against rubric.md.

## Differentiation

**If students are struggling:** Provide starter template.

**If students finish early:** Have student write custom benchmark script.
