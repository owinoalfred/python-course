# 7.6 — Core Data Libraries

**Module 7: File Handling and Working with Data**

NumPy, Pandas, Matplotlib, and Seaborn for data manipulation and visualization.

## Why this topic matters

NumPy and Pandas power modern scientific data processing pipelines.

## Learning objectives

1. Process multi-dimensional arrays with NumPy.
2. Manipulate DataFrames with Pandas.
3. Plot telemetry data using Matplotlib.
