# 7.1 — File Operations

**Module 7: File Handling and Working with Data**

open(), context managers (with statement), reading/writing text and binary files.

## Why this topic matters

File operations persist runtime state, logs, and telemetry data across program runs.

## Learning objectives

1. Open files using open().
2. Use context managers for safe cleanup.
3. Read and write text and binary data.

## Prerequisites

- Module 6 Object-Oriented Programming
