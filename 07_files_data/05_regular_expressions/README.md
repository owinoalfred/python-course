# 7.5 — Regular Expressions

**Module 7: File Handling and Working with Data**

re module (search, match, findall, sub), regex syntax, capture groups, and flags.

## Why this topic matters

Regular expressions parse complex text patterns in logs and telemetry strings.

## Learning objectives

1. Search text using re.search and re.findall.
2. Extract pattern groups.
3. Replace text with re.sub.
