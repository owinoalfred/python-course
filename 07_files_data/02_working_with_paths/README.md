# 7.2 — Working with Paths

**Module 7: File Handling and Working with Data**

pathlib module, Path objects, path manipulation, and cross-platform file paths.

## Why this topic matters

pathlib provides object-oriented, cross-platform filesystem paths.

## Learning objectives

1. Create and manipulate Path objects.
2. Check file existence, extension, and parent directories.
3. Glob directory trees.

## Prerequisites

- Topic 7.1 File Operations
