# 8.4 — CRUD Operations

**Module 8: Databases**

Create, Read, Update, Delete queries and data manipulation.

## Why this topic matters

CRUD operations are the primary database interaction primitives.

## Learning objectives

1. Execute INSERT, SELECT, UPDATE, and DELETE statements.
2. Fetch query results with fetchone() and fetchall().
3. Handle bulk operations.

## Prerequisites

- Topic 8.3 Connecting to DBs
