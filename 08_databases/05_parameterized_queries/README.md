# 8.5 — Parameterized Queries and SQL Injection

**Module 8: Databases**

SQL injection vulnerabilities, string formatting risks, and parameterized placeholders (?).

## Why this topic matters

Parameterized queries protect applications from critical SQL injection security vulnerabilities.

## Learning objectives

1. Identify SQL injection risks.
2. Use parameterized placeholders (?).
3. Never concatenate untrusted user input into SQL.
