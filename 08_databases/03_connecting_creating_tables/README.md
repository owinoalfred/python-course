# 8.3 — Connecting to Databases and Creating Tables

**Module 8: Databases**

Connection management, cursors, table schemas, and data types.

## Why this topic matters

Establishing clean database schemas prevents data corruption and type mismatch.

## Learning objectives

1. Establish database connections.
2. Use cursors for statement execution.
3. Define primary and foreign keys.

## Prerequisites

- Topic 8.2 SQLite
