# 8.2 — SQLite

**Module 8: Databases**

sqlite3 module, in-memory databases, and file-backed SQLite.

## Why this topic matters

SQLite provides zero-configuration, serverless, self-contained SQL storage.

## Learning objectives

1. Connect to SQLite using sqlite3.
2. Execute DDL statements.
3. Use in-memory sqlite3 databases.

## Prerequisites
