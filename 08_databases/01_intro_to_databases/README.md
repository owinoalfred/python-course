# 8.1 — Introduction to Databases

**Module 8: Databases**

Relational databases, SQL fundamentals, and database design.

## Why this topic matters

Databases provide persistent, transactional, and queryable state storage for fleet operations.

## Learning objectives

1. Understand relational database concepts.
2. Write basic SQL SELECT queries.
3. Design relational schema.

## Prerequisites

- Module 7 Working with Data
