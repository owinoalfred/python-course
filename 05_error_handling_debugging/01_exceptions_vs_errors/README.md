# 5.1 — Exceptions vs Errors

**Module 5: Error Handling and Debugging**

Syntax errors vs runtime exceptions, CPython exception hierarchy, and traceback analysis.

## Why this topic matters

Distinguishing syntax errors from runtime exceptions is vital for system reliability.

## Learning objectives

1. Identify syntax vs runtime errors.
2. Understand the Exception hierarchy.
3. Parse tracebacks.

## Prerequisites

- Module 4 Functions and Modules
