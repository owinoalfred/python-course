# 5.6 — Introduction to Logging

**Module 5: Error Handling and Debugging**

logging module, log levels, formatters, handlers, and configuration.

## Why this topic matters

Logging replaces ephemeral print statements with structured runtime audit trails.

## Learning objectives

1. Configure logging with logging.basicConfig().
2. Use log levels (DEBUG, INFO, WARNING, ERROR, CRITICAL).
3. Add custom formatters and handlers.

## Prerequisites

- Topic 5.5 Debugging Techniques
