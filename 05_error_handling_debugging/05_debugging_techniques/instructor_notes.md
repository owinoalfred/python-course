# Instructor notes — 5.5 Debugging Techniques

**Module 5: Error Handling and Debugging**

## Teaching objectives

- Teach core concept of Debugging Techniques.
- Guide students through edge cases.

## Likely misconceptions

| Misconception | Correction to drive home |
| --- | --- |
| Thinking Debugging Techniques is static | Clarify dynamic runtime execution in CPython |

## Difficult concepts

- Understanding edge-case handling in Debugging Techniques.

## Demonstration suggestions

- Live demo of Debugging Techniques in python REPL.

## Discussion questions

- Why is Debugging Techniques preferred in this context?

## Common student errors

| Error | Why it happens | Intervention |
| --- | --- | --- |
| IndexError / KeyError in Debugging Techniques | Accessing elements without bounds check | Add length check or try-except |

2 hours lecture + 3 hours lab exercises.

## Extension activities
