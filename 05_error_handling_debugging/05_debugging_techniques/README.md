# 5.5 — Debugging Techniques

**Module 5: Error Handling and Debugging**

pdb, breakpoint(), inspection methods, and post-mortem analysis.

## Why this topic matters

Systematic debugging skills reduce mean time to resolution.

## Learning objectives

1. Use breakpoint() for interactive debugging.
2. Inspect runtime scope using dir(), vars(), and type().
3. Perform post-mortem stack inspection.
