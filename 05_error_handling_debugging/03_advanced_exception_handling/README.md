# 5.3 — Advanced Exception Handling

**Module 5: Error Handling and Debugging**

Exception groups (Python 3.11+), except*, raising exceptions with context, and suppression.

## Why this topic matters

Exception groups handle concurrent or batched errors in modern Python.

## Learning objectives

1. Work with ExceptionGroup and except*.
2. Suppress non-critical exceptions cleanly.
3. Chain error contexts.

## Prerequisites
