# 5.2 — Exception Handling

**Module 5: Error Handling and Debugging**

try, except, else, finally blocks and exception chaining.

## Why this topic matters

finally blocks guarantee resource cleanup regardless of execution success or error.

## Learning objectives

1. Construct try-except-else-finally blocks.
2. Avoid bare except clauses.
3. Clean up system resources in finally.

## Prerequisites

- Topic 5.1 Exceptions vs Errors
