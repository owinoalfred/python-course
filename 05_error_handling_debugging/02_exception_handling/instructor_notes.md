# Instructor notes — 5.2 Exception Handling

**Module 5: Error Handling and Debugging**

## Teaching objectives

- Teach core concept of Exception Handling.
- Guide students through edge cases.

## Likely misconceptions

| Misconception | Correction to drive home |
| --- | --- |
| Thinking Exception Handling is static | Clarify dynamic runtime execution in CPython |

## Difficult concepts

- Understanding edge-case handling in Exception Handling.

## Demonstration suggestions

- Live demo of Exception Handling in python REPL.

## Discussion questions

- Why is Exception Handling preferred in this context?

## Common student errors

| Error | Why it happens | Intervention |
| --- | --- | --- |
| IndexError / KeyError in Exception Handling | Accessing elements without bounds check | Add length check or try-except |

## Recommended pacing

2 hours lecture + 3 hours lab exercises.

## Extension activities

- Advanced optimization profiling.

## Assessment advice

Evaluate against rubric.md.
