# Module 2 — Control Flow and Loops

**Directory:** `02_control_flow/` &nbsp;|&nbsp; **ROBO-X milestone:** M2 &nbsp;|&nbsp; **Topics:** 5

Learn to direct the flow of a program with conditionals and loops. You will branch on sensor thresholds, iterate over waypoint lists, use break and continue deliberately, and pair up data streams with range, enumerate and zip.

## What you will be able to do

- Write branching logic with ``if``/``elif``/``else`` and the conditional expression.
- Iterate with ``for`` and ``while``, and choose the right loop for a task.
- Control loops deliberately with ``break``, ``continue`` and ``else``.
- Use ``range``, ``enumerate`` and ``zip`` to iterate with indices and pair streams.
