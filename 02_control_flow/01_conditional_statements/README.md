# 2.1 — Conditional Statements

**Module 2: Control Flow and Loops**

if, elif, else, nested conditions, and boolean truthiness in decision engine control logic.

## Why this topic matters

Conditionals enable software to make dynamic execution choices based on runtime state.

## Learning objectives

1. Evaluate boolean conditions.
2. Implement nested logic.
3. Understand truthiness in Python.

## Prerequisites

- Module 1 Getting Started
