# 9.3 — Command-Line Interfaces

**Module 9: Intermediate Practical Skills and Best Practices**

argparse module, positional and optional flags, subcommands, and sys.argv parsing.

## Why this topic matters

Command-line interfaces allow automation and configuration of python tools.

## Learning objectives

1. Build CLI tools with argparse.
2. Define subcommands and flags.
3. Parse CLI arguments safely.
