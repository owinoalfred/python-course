# 9.7 — Project Structure and Packaging

**Module 9: Intermediate Practical Skills and Best Practices**

src layout vs flat layout, pyproject.toml configuration, setuptools, and wheel generation.

## Why this topic matters

Professional project structure allows Python libraries to be distributed and installed.

## Learning objectives

1. Organize code into src/ package layout.
2. Configure pyproject.toml with setuptools build-backend.
3. Build installable wheels.

## Prerequisites

- Topic 9.6 Code Style
