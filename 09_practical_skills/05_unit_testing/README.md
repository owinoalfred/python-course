# 9.5 — Unit Testing

**Module 9: Intermediate Practical Skills and Best Practices**

pytest framework, assert statements, fixtures, test discovery, and mocking.

## Why this topic matters

Automated unit testing prevents regressions and validates component specifications.

## Learning objectives

1. Write pytest test functions with assertions.
2. Use pytest fixtures.
3. Mock external dependencies with unittest.mock.
