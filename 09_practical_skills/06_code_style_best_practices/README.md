# 9.6 — Code Style and Best Practices

**Module 9: Intermediate Practical Skills and Best Practices**

PEP 8 compliance, flake8, black, isort, docstrings, and refactoring clean code.

## Why this topic matters

Consistent code style improves code maintainability across engineering teams.

## Learning objectives

1. Adhere to PEP 8 style guidelines.
2. Use automated formatters like black and flake8.
3. Refactor messy code into clean idiomatic Python.

- Topic 9.5 Unit Testing
