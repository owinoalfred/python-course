# 9.1 — Type Hints

**Module 9: Intermediate Practical Skills and Best Practices**

Type annotations, typing module (Union, Optional, Any, Callable), mypy, and runtime type checking.

## Why this topic matters

Type hints document API expectations, catch bugs statically, and improve IDE completion.

## Learning objectives

1. Annotate variables, functions, and return types.
2. Use typing module generics.
3. Run static type checks.

## Prerequisites

- Module 8 Databases
