# 3.6 — Looping Through Data Structures

**Module 3: Core Data Structures**

Iterating over lists, dicts, sets, tuples, and nested structures.

## Why this topic matters

Selecting the correct iteration pattern prevents bugs and optimizes runtime.

## Learning objectives

1. Iterate over dict items.
2. Safely mutate structures during iteration.
3. Process nested collections.

## Prerequisites

- Topic 3.5 Strings
