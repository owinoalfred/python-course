# 3.1 — Lists

**Module 3: Core Data Structures**

Dynamic arrays, indexing, slicing, mutability, and list methods.

## Why this topic matters

Lists are the primary ordered collection structure in Python.

## Learning objectives

1. Manipulate dynamic lists.
2. Master indexing and slicing.
3. Understand list memory allocation.

## Prerequisites

- Module 2 Control Flow
