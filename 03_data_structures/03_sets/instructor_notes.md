# Instructor notes — 3.3 Sets

**Module 3: Core Data Structures**

## Teaching objectives

- Teach core concept of Sets.
- Guide students through edge cases.

## Likely misconceptions

| Misconception | Correction to drive home |
| --- | --- |
| Thinking Sets is static | Clarify dynamic runtime execution in CPython |

## Difficult concepts

- Understanding edge-case handling in Sets.

## Demonstration suggestions

- Live demo of Sets in python REPL.

## Discussion questions

- Why is Sets preferred in this context?

## Common student errors

| Error | Why it happens | Intervention |
| --- | --- | --- |
| IndexError / KeyError in Sets | Accessing elements without bounds check | Add length check or try-except |

## Recommended pacing

2 hours lecture + 3 hours lab exercises.

## Extension activities

- Advanced optimization profiling.

## Assessment advice

Evaluate against rubric.md.

## Differentiation

**If students are struggling:** Provide starter template.
