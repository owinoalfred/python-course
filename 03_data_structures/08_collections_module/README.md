# 3.8 — collections Module

**Module 3: Core Data Structures**

Counter, defaultdict, namedtuple, and deque from standard collections.

## Why this topic matters

Standard collections extend basic structures with optimized data abstractions.

## Learning objectives

1. Count elements with Counter.
2. Handle missing keys with defaultdict.
3. Use deque for FIFO queues.
