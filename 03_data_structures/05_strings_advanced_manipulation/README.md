# 3.5 — Strings and Advanced String Manipulation

**Module 3: Core Data Structures**

String immutability, formatting, splitting, joining, and regex fundamentals.

## Why this topic matters

Strings process text protocols, logs, serializations, and command inputs.

## Learning objectives

1. Master string slicing and splitting.
2. Parse structured log lines.
3. Format strings efficiently.

## Prerequisites

- Topic 3.4 Dictionaries
