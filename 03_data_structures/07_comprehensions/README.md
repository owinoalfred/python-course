# 3.7 — Comprehensions

**Module 3: Core Data Structures**

List, dict, set, and generator comprehensions.

## Why this topic matters

Comprehensions provide concise, highly optimized syntax for transforming collections.

## Learning objectives

1. Write list comprehensions with filters.
2. Construct dict and set comprehensions.
3. Understand generator expressions.

## Prerequisites

- Topic 3.6 Looping
