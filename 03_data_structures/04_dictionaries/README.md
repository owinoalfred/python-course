# 3.4 — Dictionaries

**Module 3: Core Data Structures**

Key-value mapping data structures, dict methods, and hash maps.

## Why this topic matters

Dictionaries enable efficient key-based lookup for state management and configuration.

## Learning objectives

1. Work with key-value pairs.
2. Use dict methods safely.
3. Understand dictionary key immutability.
