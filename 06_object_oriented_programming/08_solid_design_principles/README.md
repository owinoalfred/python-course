# 6.8 — SOLID Design Principles

**Module 6: Object-Oriented Programming**

Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, and Dependency Inversion in Python.

## Why this topic matters

SOLID principles guide object-oriented architecture toward maintainable, extensible code.

## Learning objectives

1. Apply Single Responsibility Principle.
2. Design Open/Closed extensible classes.
3. Apply Dependency Inversion with interfaces.

## Prerequisites

- Topic 6.7 Composition vs Inheritance
