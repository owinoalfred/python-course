# 6.4 — Polymorphism and Abstraction

**Module 6: Object-Oriented Programming**

Method overriding, duck typing, abc module, and @abstractmethod.

## Why this topic matters

Polymorphism allows uniform treatment of different underlying class implementations.

## Learning objectives

1. Override methods in subclasses.
2. Use duck typing effectively.
3. Define abstract base classes with abc.

## Prerequisites

- Topic 6.3 Inheritance
