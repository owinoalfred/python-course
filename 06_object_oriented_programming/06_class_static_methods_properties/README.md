# 6.6 — Class Methods, Static Methods, and Properties

**Module 6: Object-Oriented Programming**

@classmethod, @staticmethod, and @property decorators.

## Why this topic matters

Properties and class methods offer clean factory constructors and attribute encapsulation.

## Learning objectives

1. Create factory constructors with @classmethod.
2. Define utility functions with @staticmethod.
3. Manage getters/setters with @property.

- Topic 6.5 Magic Methods
