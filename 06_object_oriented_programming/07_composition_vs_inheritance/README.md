# 6.7 — Composition vs Inheritance

**Module 6: Object-Oriented Programming**

HAS-A vs IS-A relationships and object composition patterns.

## Why this topic matters

Favoring composition over inheritance produces loosely coupled, flexible designs.

## Learning objectives

1. Distinguish IS-A vs HAS-A relationships.
2. Compose complex objects from smaller components.
3. Refactor deep inheritance hierarchies into composed designs.

## Prerequisites

- Topic 6.6 Class/Static Methods
