# 6.1 — OOP Fundamentals

**Module 6: Object-Oriented Programming**

Classes, instances, __init__, self, and instance attributes.

## Why this topic matters

Object-oriented programming structures state and behavior into cohesive entities.

## Learning objectives

1. Define classes with __init__.
2. Instantiate objects and pass self.
3. Manage instance attributes.

## Prerequisites

- Module 5 Error Handling
