# 6.3 — Inheritance

**Module 6: Object-Oriented Programming**

Single and multiple inheritance, super(), and Method Resolution Order (MRO).

## Why this topic matters

Inheritance allows subclasses to reuse and extend parent class behavior.

## Learning objectives

1. Subclass existing classes.
2. Use super() to call parent methods.
3. Understand C3 linearization and MRO.

## Prerequisites

- Topic 6.2 Encapsulation
