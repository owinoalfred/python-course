# 6.2 — Encapsulation and Access Modifiers

**Module 6: Object-Oriented Programming**

Public, protected (_), private (__) attributes, and name mangling.

## Why this topic matters

Encapsulation hides internal state and exposes clean public interfaces.

## Learning objectives

1. Use single underscore for protected members.
2. Understand double underscore name mangling.
3. Enforce API boundaries.

## Prerequisites

- Topic 6.1 OOP Fundamentals
