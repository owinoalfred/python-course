# 6.5 — Special / Magic Methods

**Module 6: Object-Oriented Programming**

__str__, __repr__, __len__, __getitem__, __add__, and dunder protocols.

## Why this topic matters

Magic methods allow custom classes to integrate seamlessly with Python built-in operations.

## Learning objectives

1. Implement string representations with __str__ and __repr__.
2. Overload arithmetic operators.
3. Implement sequence protocols with __len__ and __getitem__.
